1. Pooja Sub-Menu (Rituals, Sevas & Slot Inventory)

Frontend: EventsPoojaSeva.tsx • Dedicated Route: /events/pooja

5 Database Tables Pointed

Key Capabilities & UI Features:

  • • Pooja Master Configuration: Setup rituals with Pandit name, mandap location, fee/free flag, required items checklist, and multi-day flags.
  • • Granular Slot Schedules: Configure multi-day time slots with family capacity and devotee capacity constraints.
  • • Ephemeral Slot Locking: 10-minute temporary locks via event_pooja_slot_reservation to prevent race conditions during Sankalpam bookings.
  • • Devotee Registration Ledger: View Gotram, attending family members, Sankalpam token numbers, and prasadam delivery mode (mandap/home).

APIs & Database Tables Pointed:

GET/POST /api/events/pooja-sevas → event_pooja_sevas

GET /api/events/pooja-types → event_pooja_types

GET/POST /api/events/pooja-schedules → event_pooja_schedule

GET /api/events/pooja-schedules/{id}/reservations → event_pooja_slot_reservation

GET/POST /api/events/registrations?category=Pooja → event_booking_registrations & event_pooja_user_registrations

2. Event Sub-Menu (Parent Festivals, Timelines & Creation)

Frontend: EventsCreate.tsx, EventsPrograms.tsx, EventSchedule.tsx • Routes: /events/create, /events/schedule

6 Database Tables Pointed

Key Capabilities & UI Features:

  • • Multi-Step Event Wizard: Basic details, cover image upload, registration rules, UPI payment scanner configuration, and emergency contacts.
  • • Sub-Activity Orchestration: Automatically creates connected Poojas, Meals, Cultural shows, and Contests tied to the main_event_id.
  • • Program Agenda Timeline: Day-wise and hourly agenda schedule with performer names, stage locations, and time slots.
  • • Ticket Tiers & Categories: Master category configuration (*VIP Pass, General Devotee, Early Bird*) and pricing allocations.

APIs & Database Tables Pointed:

GET/POST /api/events → event_community

GET/POST /api/events/programs → event_program

GET/POST /api/events/ticket-categories → event_ticket_categories

GET /api/events/ticket-category-master → event_ticket_category_names

GET/POST /api/events/venues → event_venues & event_venue_config

👥

3. People Sub-Menu (Volunteers, Registered Users & Venues)

Frontend: EventsPeople.tsx, EventsVolunteers.tsx, EventsRegistration.tsx, EventsVenue.tsx • Route: /events/people

5 Database Tables Pointed

Key Capabilities & UI Features:

  • • Registered Users Tab: Searchable attendee ledger with Gotram, headcount, category filters, CSV/JSON export, and batch pass printing.
  • • Volunteers Tab: Volunteer duty assignment across departments (*Gate Security, Food & Kitchen, Stage Audio, Medical*), shift schedules, and live Check-In/Check-Out timestamps.
  • • Venue Tab: Physical grounds configuration, address, seating capacity, contact persons, and stage audio-visual configurations.
  • • Check-In Verification: Real-time gate arrival marking and pass validation.

APIs & Database Tables Pointed:

GET/POST /api/events/{id}/registrations → event_booking_registrations & event_registration

GET/POST /api/events/volunteers → event_volunteer

PATCH /api/events/volunteers/{id}/checkin → event_volunteer

GET/POST /api/events/departments → event_department

GET/POST /api/events/venues → event_venues & event_venue_config

GET /api/events/family-members → event_family_members
